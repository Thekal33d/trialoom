## Application foundation

RUN-01 now connects actual Chromium execution of the owned invitation fixture to HTTP evidence ingestion and the builder workspace. Fresh reports remain pending review, raw trace bytes stay private, and a repaired fixture produces a passing outcome with the same driver. [RUN-02](RUN-02.md) now adds recorded inspection and metadata-only trace downloads with verified hashes. Cancellation, expiry, revocation, unavailability, and time caps are checked. This is controlled local execution with administrative setup, not a hosted independent operator. [Design](RUN-01.md), [evidence](evidence/RUN-01.json).

ALPHA-01 passed a clean lockfile install, lint/type/build checks, seven disposable-database checks, and 18 desktop/mobile browser checks. The demo exports a fixture summary and leaves independent acceptance/payment unavailable. [Evidence](evidence/ALPHA-01.json) records versions, source hashes, and limits. Queue lease tests cover the harmless smoke handler; they do not establish the assignment or financial invariants below.

ALPHA-11 turned the whole sequence into one repeatable command. `npm run loop` runs a seeded campaign against a disposable database and the real server modules — publication, two independent reports confirming one defect, decisions, four separate payables, a blocked payout that stays owed, settlement through inclusion to finality, crash-after-broadcast recovery, a fenced lapsed claim, a quoted and independently verified repair, a capped resource purchase with an uncertain one holding its reservation, the queue, and an export whose hash is verified from the file itself. It asserts as it goes and exits non-zero on the first failure. [ALPHA-11 evidence](evidence/ALPHA-11.json) records the transcript and the three boundaries it cannot cross: harness-produced evidence, a fixture payment authority, and a fixture resource provider.

ALPHA-02 added invitation-only sessions, workspace roles, authorized project/build records, and immutable draft terms. ALPHA-03 added operator registration, EIP-4361 wallet control, scoped revocable agent credentials, seeded qualification grading with derived eligibility, and a versioned agent API with idempotent mutations. ALPHA-04 added the campaign ledger, publication of one exact terms version, atomic claims that pin terms and build, renewable leases with attempt fencing, and pause and cancellation that preserve accepted obligations. ALPHA-05 added platform-side target revalidation, lease-bound single-purpose run grants, evidence ingestion with schema, identity, size and time checks, and private storage with verified redaction. ALPHA-06 added deterministic defect clustering, the independence rule that keeps a linked operator from reproducing its own finding, and immutable decisions that carry the criteria, reason, evidence references and actor behind every acceptance, refusal, grouping, severity change and appeal. ALPHA-08 added payables written atomically with their outbox jobs, an immutable payout identity that a retry reconciles instead of replacing, separate included and finalized states, and separate operator and fee transfers. [ALPHA-08 evidence](evidence/ALPHA-08.json) records 118 database checks, 44 browser checks, and the gates that remain: no funded payment authority exists, so no transfer has happened; Trialoom neither hosts nor sandboxes the runner; archives have no reviewed export path; and reproduction cannot be commissioned.
